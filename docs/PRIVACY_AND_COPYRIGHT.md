# Privacy And Copyright

Video Notes Agent is local-first.

## Privacy

- Local video transcription uses open-source Whisper through `faster-whisper`.
- No hosted AI API is required for normal use.
- Internet video downloads, if enabled, are handled by user-invoked tooling such as `yt-dlp`.
- Generated transcripts, screenshots, and DOCX files are saved locally under the selected output folder.

## Copyright

Users are responsible for ensuring they have the right to access and process source videos.

Do not use this project to:

- bypass DRM
- bypass paywalls or unauthorized access controls
- redistribute copyrighted course screenshots
- publish transcripts or notes where the source license forbids it

For copyrighted/private training material, generated notes should normally remain personal study artifacts.
